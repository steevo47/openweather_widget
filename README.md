5 Day weather forecast widget for Homarr using OpenWeatherMap free API.

You'll need to create a free account at https://openweathermap.org to get an API

API URL for this widget: https://api.openweathermap.org/data/2.5/forecast?lat=YOUR_LATITUDE&lon=YOUR_LONGITUDE&units=imperial&appid=YOUR_API_KEY

Obviously, replace YOUR_LATITUDE, YOUR_LONGITUDE, and YOUR_API_KEY with your information
